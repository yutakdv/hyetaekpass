# 혜택패스 검증판 설계

GOAL_PROMPT.md와 통합 기획서·docs/00~05 전체를 읽은 기준이다. 사용자는 일반 설계·기술·구현 결정을 위임하고 중간 승인 대기를 금지했다. 공유 contracts, TypeScript 계산 엔진, 루트 의존성은 총괄 한 명이 작성한다. 전문 역할은 별도 에이전트에 실제 위임한다.

React Native + Expo development build, Spring Boot + Java 25 LTS, PostgreSQL 단일 서버를 사용한다. Expo는 작은 양 OS 빌드와 권한 연동을 위한 선택이며 Expo Go는 기기 검증 증거가 아니다. 정적 파일만의 대안은 운영 검수·제보 요구를 충족하지 못하고 다중 서버는 현 규모에 불필요하다. 관리 화면은 Vite + TypeScript로 같은 엔진을 사용한다. Python 표준 CSV/JSON 파서는 자료 후보와 변경 비교만 담당한다.

공개 카탈로그는 허가·실제 독립 원문 검수 전 0개다. 성수 생활권은 개발 가정, 가상 브랜드 3개와 자료는 테스트 fixture에만 둔다. 사용자 직접작성 규칙과 지갑은 로컬 보호 저장하며 미검수 표시한다. 카드 번호, CVC, 금융 로그인·계좌·이동 이력·push token을 받지 않는다.

contracts는 integer KRW/basis points, UTC RFC3339 반개구간, KST 기준월, TRUE/FALSE/UNKNOWN, 명시적 정산·순서·기준·상한·반올림, API 오류를 고정한다. 엔진은 한 카드와 최대 한 멤버십만 계산하고 UNKNOWN은 합계·순위에서 제외한다. 명시적 허용·검수된 조합만 합산한다.

bootstrap 안전 overlay를 먼저 영속 반영한 뒤 크기·해시·Schema·참조·호환·기간을 검증한 카탈로그만 원자 교체한다. 실패는 안전 확인 시각을 연장하지 않는다. 24시간·원문·혜택·권리 중 가장 이른 기한을 지키고 시계 회귀·불확실성에는 보류한다. 차단은 롤백과 독립이다.

서버는 자료 입력·형식 검사·실제 사람 검수 기록·게시·차단·롤백·제보 inbox/분류/종결/삭제·감사를 DB에 연결한다. 운영 인증은 기존 OIDC와 MFA/관리자 허용 목록으로 닫고, loopback 개발 프로필만 명시적으로 분리한다. 독립 journal은 로컬 fsync 볼륨/운영 private versioned S3에 먼저 기록하고 DB에 멱등 적용한다. 복구 후 journal 재적용 전 정상 bootstrap을 내지 않는다.

전경 위치는 목적별 동의와 OS 권한 후 단말 거리순 목록을 만든다. 배경 파일럿은 OS/장소 flag 모두 기본 OFF, 실제 관측 3회·120초·공백≤60초·age≤30초·정확도≤50m·거리+정확도≤150m, 수명 5분, KST 21~08시 금지·하루2건·24시간 쿨다운을 정책으로 검사한다. JS 타이머나 예약 알림을 체류 근거로 쓰지 않는다. 실제 기기·법률·권리·심사 증거 전 공개 활성화하지 않는다.

검증은 계산/안전 Node 테스트, Python CLI 테스트, Java/PostgreSQL 통합·복구, 새 Compose migration, 관리/모바일 화면 실행, iOS·Android 네이티브 빌드를 각각 수행·기록한다. 실기기·서명·권리·독립 사람 검수·AWS 비용 발생·공개 배포·스토어 승인은 별도 외부 게이트다. 실제 실행 증거 없는 항목을 완료로 표시하지 않는다.
