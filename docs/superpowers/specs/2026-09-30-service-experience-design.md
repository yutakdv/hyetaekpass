# 혜택패스 서비스 경험 구현 설계

2026-09-30. 사용자 위임에 따라 구현까지 진행한다. 화면별 결정은 `docs/service-experience-spec.md`, `docs/service-ui-design.md`의 P0/SX01~14를 따른다. 네 가지 탭(홈·탐색·지갑·저장), 독립 상세/편집/설정 화면, 세 단계 결제 확인을 제공한다. 공개 자료 0개에서도 지갑 → 내 조건 → 저장 → 결제 확인 과업을 완결한다. 예시는 앱 정보에서 명시적으로 격리한다.

## 구현 경계

- root: App controller, 보호 저장 호환 모델, 정확한 %/한국 날짜 변환, 최신 상태 기반 저장 직렬화와 삭제 세대, 계산/시간/안전/권한 통합, 의존성, 검증·Git.
- frontend: ServiceUI 및 UI props 계약. 입력 draft는 화면에 유지하고 다음/저장 시 전달한다. 화면에서 계산·네트워크·디스크를 직접 실행하지 않는다.
- service_design: 관리자 업무 화면(대시보드·자료/검수·제보·안전·감사). 기존 API·권리·사람 검수·운영자 역할을 유지한다.

기존 LocalData 필드는 유지하며 onboarding/default수단·즐겨찾기40·최근10·미완성 draft40을 호환 기본값으로 확장한다. 저장/최근은 origin과 ID/시각만 보관하고 현재 catalog에 다시 연결한다. 금액·예상액·TRUE 결과·원문 복사본을 남기지 않는다. 미완성 조건은 Rule과 별도 보관한다. 지갑 삭제/조건 삭제는 연결 참조를 정리한다. 기존 install marker와 보호 저장 key를 바꾸지 않는다.

네트워크 갱신은 로컬 편집을 막지 않는다. 하나의 단말 쓰기 큐에서 최신 LocalData에 mutation을 적용하고 cache 쓰기·전체 삭제도 직렬화한다. 삭제는 세대를 먼저 증가시키며 이전 응답은 반영하지 않는다. 실패한 저장은 기존 정상 자료와 입력을 유지한다. 계산은 기존 TS 엔진만 호출하며 PUBLIC/PERSONAL/DEMO를 혼합하지 않는다. 공개 안전 만료·차단·시각 불확실 시 화면 결과도 보류한다.

%는 소수 두 자리까지 정확히 정수 bp로 바꾸고 종료 날짜는 한국 날짜 다음 날 00시의 exclusive endsAt으로 변환한다. 기존 시간 단위 조건의 값은 편집 시 보존한다. 미확인 basis/rounding/settlement/기간은 임의 기본 산식을 만들지 않는다. 새 UI 의존성은 Expo 공식 SDK 호환 safe-area-context와 vector-icons만 사용한다. 새로운 navigation/state/form 프레임워크는 추가하지 않는다.

제보는 기존 POST/DELETE와 opaque 삭제 토큰을 사용한다. 서버 상태를 추정하지 않는다. 후속 수정은 명시적 기존 제보 DELETE → 새 POST이며 단계별 실패와 토큰 보존을 구분한다. 관리자 CLOSED는 검토 종료이지 해결 보증이 아니다. 단말 삭제는 네트워크와 무관하게 먼저 완료한다.

## 완료 증거

신규 모델 경계/호환 migration/날짜·퍼센트/동시쓰기·삭제세대/참조 무효화를 실행 검사한다. 기존 계산·안전·제보 회귀, typecheck, web/admin 빌드, 실제 API·브라우저 신규/재방문/UNKNOWN/저장·편집·제보·삭제 과업을 실행한다. 변경한 JS/의존성을 포함한 iOS·Android 네이티브 빌드를 다시 확인한다. 320px/390px/확대/키보드/접근성 표시는 실제 확인 환경별 기록한다. 실물 기기·VoiceOver/TalkBack·AWS·권리·독립 사람 검수·법률·스토어는 해당 증거 없이는 통과로 기록하지 않는다.
