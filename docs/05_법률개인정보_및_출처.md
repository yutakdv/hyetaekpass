# 혜택패스 법률 개인정보와 조사 출처

기준일은 2026년 9월 30일이다. 이 문서는 공식 자료에서 확인한 요건, 이 프로젝트의 잠정 설계, 실제 사업 주체가 확인해야 할 질문을 구분한다. **단말에서 위치를 처리한다는 사실만으로 신고·동의·광고·개인정보 의무가 면제된다고 결론 내리지 않는다.** 허가·신고·외부 법률자문을 받은 문서가 아니라 개발 전 검토 자료다.

## 1 기능별 확인할 의무

| 기능 | 확인한 공식 근거 | 프로젝트에서 해야 할 확인 |
|---|---|---|
| 위치를 이용한 주변 검색·알림 | 위치정보법 제9조, 제9조의2, 제16조, 제19조 | 실제 데이터 흐름의 사업 분류, 신고 주체·시점·소규모 자격, 약관·동의·보호·확인자료 기록 |
| 카드·멤버십 자료 가공·배포 | 저작권법 제93조와 소스 이용조건 | 요약·산식 변환·원시 JSON 단말 배포·상표·갱신·삭제에 허용된 범위 |
| 할인·쿠폰 알림 | 정보통신망법 제50조, KISA 광고성 정보 안내 | 사용자 요청 기능의 광고성 분류, 선택 동의·철회·표시·연락처·야간 제한 |
| 제보·로그·운영자 인증 | 실제 처리하는 개인정보와 보호법 | 처리 목적·법적 근거·최소 항목·보존·삭제·위탁·권리 행사 |
| 해외 SDK·서버 push·외부 AI | 개인정보 보호법 제28조의8 | 실제 국외 처리 대상·국가·수탁사·재위탁·근거·고지. 서울 리전만으로 해결되지 않음 |
| 금융내역 자동 연동 | 별도 금융 데이터·계약 검토 | 초기에는 제공하지 않음. 공식 연동과 사업 분류 확인 전 로그인 수집·스크래핑 금지 |
| 공개 모바일 배포 | Apple·Google의 권한·개인정보·지식재산 정책 | 실제 바이너리·SDK·동의 화면·신고 영상·지원 URL과 제출 내용 일치 |

관련 조문은 [위치정보법 제9조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900340011), [제9조의2](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1001000183), [제16조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029559843), [제19조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029559611), [저작권법 제93조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029423451), [정보통신망법 제50조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025057501), [국외 이전 제28조의8](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334953)에서 확인했다.

## 2 위치 서비스의 사업 분류

현행 위치정보법 제9조에는 개인위치정보를 이용한 위치기반서비스사업의 신고 규정이 있다. 제9조의2의 소규모 특례는 법에 정한 소상공인·1인 창조기업 자격과 사업 지속 시 신고기한을 따로 다룬다. 개발자가 한 명이거나 학생이라는 이유만으로 자격을 충족하거나 계속 신고가 면제된다고 해석하지 않는다. 조문에 기재된 기관은 방송미디어통신위원회이며 실제 접수 절차는 담당 기관의 현행 안내로 확인한다.

확인 요청에는 다음 흐름을 구체적으로 제시한다. 지도 좌표는 공개 점포 자료에서 내려받고, 사용자 현재 위치는 OS에서 앱으로 전달되며, 거리 계산·후보·알림은 단말에서 수행한다. 서버에는 지역 선택 코드·카탈로그 요청·선택적 제보와 접속 로그만 간다. 계정·이동 이력·지갑 동기화는 없다.

이 구조에서 사업 분류·신고·약관·동의·이용 확인자료의 기록 주체·항목·법정 보존기간을 확인한다. 원시 GPS 경로를 보관하지 않는 설계와 법에서 요구하는 확인 기록은 다른 문제다. 법정 기록이 필요한데 단말 메모리 정책만으로 삭제하면 된다고 약속하지 않는다. 기록이 필요한 경우 최소 이벤트와 접근 제한을 설계에 반영한 후 위치 기능을 제공한다.

공식 상담과 자격 확인 출발점은 [위치정보지원센터](https://www.lbsc.kr/index.do), [소규모 위치기반서비스사업 신고 안내](https://www.emsit.go.kr/cp/cv/Cp1440000_0182_03Reg.do)다. 아직 이 프로젝트에 대한 유권해석이나 자격 확인은 없다.

## 3 동의와 사용 흐름

| 시점 | 설명과 선택 | 거절·철회 시 동작 |
|---|---|---|
| 첫 실행 | 지원 범위와 로컬 지갑 설명 | 권한 없이 수동 검색·입력 사용 |
| 주변 찾기를 직접 누름 | 위치 사용 목적·처리 방식 설명 후 사용 중 권한 | 수동 지역·점포 선택 유지 |
| 백그라운드 안내를 켬 | 필요한 서비스 약관·선택 기능·OS 배경 권한을 단계적으로 설명 | 기본 사용 유지, 지역 등록과 후보 정리 |
| 알림을 켬 | 표시 목적·빈도·조용한 시간 설명 후 OS 알림 권한 | 앱 안의 혜택 목록 유지 |
| 광고로 분류된 안내 선택 | 명확한 광고성 정보 수신 동의와 철회 수단 | 광고 알림 중지. 핵심 검색을 막지 않음 |
| 전체 삭제 | 지갑·상태·캐시·보호 키·예약 알림·제보 삭제 방법 안내 | 법정 보존이 필요한 기록은 근거·기간을 별도 설명 |

OS 위치·알림 허용은 서비스 약관 동의 또는 광고 수신 동의를 대신하지 않는다. 기능 설정과 법률 동의를 묶어 필수 선택으로 만들지 않는다. 동의 버전·시각·목적·철회 증거의 보존은 실제 적용 의무에 맞춰 정한다. 초기 대상은 성인 파일럿으로 좁히고 미성년자 서비스를 추가하면 동의·계정·보호 정책을 별도 검토한다.

## 4 광고 알림의 처리

정보통신망법 제50조는 광고성 정보의 사전 동의·거부·철회와 야간 전송을 규정한다. 할인·쿠폰이라는 표현, 이용자가 즐겨찾기를 선택했다는 사실, 로컬 알림이라는 구현만으로 예외를 선언하지 않는다. 실제 이용자 요청 내용·메시지·전송 목적을 검토한다.

KISA가 2026년 3월 4일 게시한 제7차 안내의 공식 요약은 광고 동의를 모호한 혜택 알림 문구로 받는 문제, 복잡한 앱 수신 거부 절차, 임의 지급 쿠폰 만료 안내를 다룬다. 이에 따라 법률 동의 화면은 “광고성 정보 수신 동의”처럼 목적을 명확히 쓰고 앱에서 쉽게 끌 수 있게 한다. [KISA 제7차 안내 게시물](https://spam.kisa.or.kr/spam/na/ntt/selectNttInfo.do?bbsId=1002&mi=1020&nttSn=3001)

초기 설계는 21:00~08:00 광고 알림을 제공하지 않는다. 해당 시간에 억제한 위치 알림을 다음 아침에 몰아서 보내지 않는다. 광고로 분류될 경우 광고 표시·발신자·연락처·무료 수신 거부 등 요구를 실제 OS 화면 형식에서 확인한다. 문구만 바꿔 정책을 우회하지 않는다.

사용자 선택 지역 안내도 이 절차와 플랫폼 백그라운드 위치 심사를 따른다. 사용자가 원하는 지역 정보인지와 피로를 시험하는 제품 판단은 광고성의 법률 판단과 별개다.

## 5 개인정보 최소화와 보존 제안

아래 기간은 비필수 제품 데이터의 설계 제안이며 법정 기간이 아니다. 법률·계약상 보존 의무가 확인되면 항목별로 조정하고 개인정보처리방침에 실제 구현을 반영한다.

| 항목 | 기본 설계 | 보존·삭제 제안 |
|---|---|---|
| 지갑·사용자 입력 조건 | 단말 보호 저장, 금융 인증정보·카드 번호 없음 | 사용자가 수정·전체 삭제. 백업 제외 또는 명시된 보호 방식 |
| 현재 위치 | 기본 메모리 처리, 서버·분석 SDK 전송 없음 | 후보 수명 종료 시 폐기. 이동 경로 기본 저장 없음 |
| 알림 쿨다운·횟수 | 지역·브랜드 단위 최소 로컬 상태 | 24시간 등 정책에 필요한 기간 후 정리 |
| 일반 HTTP 접속 로그 | 요청 본문 제외, 운영에 필요한 IP 등 최소 정보 | 7일 제안. 개인정보처리시스템 접속·관리 감사·사건 기록과 구별 |
| 개인정보처리시스템 접속·관리 감사 | 제보 조회·다운로드·삭제 등 수행자·시각·업무를 최소 기록 | 해당 안전성 확보조치 기준의 법정 기간·점검·보호 적용. 일반 HTTP의 7일 삭제안을 적용하지 않음 |
| 오류·crash | 좌표·지갑·검색문·제보 본문·토큰 제외 | 오류 로그 30일 제안. SDK 기본 수집을 먼저 확인 |
| 오류 제보 | 연락처 없이 제출 가능, 민감 입력 경고, 삭제 토큰 | 종결 후 30일·최대 90일 제안. 필요 없는 본문 우선 삭제 |
| 파일럿 현장 시험 | 별도 연구 동의, 필요한 시간·정답·기기 상태만 | 분석 완료 후 삭제. 기간과 참여자 철회 방법 사전 확정 |
| 동의·법정 확인자료 | 목적·버전·법정 항목으로 분리 | 적용 법령에 따라 확정. 위 캐시 TTL로 일괄 삭제하지 않음 |
| 백업과 삭제 기록 | 접근 제한 DB backup, 복구 후 재삭제할 최소 기록 | 초기 backup 7일 제안. 삭제 증거에 원문 본문·좌표를 넣지 않음 |

“계정 없음”과 “개인정보 수집 없음”은 같은 말이 아니다. 서버 접속의 IP, 제보 자유 입력, 관리 인증, 실제 오류 SDK를 목록화한다. 앱 내 입력이 로컬에 남더라도 기기 백업·crash·화면 캡처 기능이 외부 전송하는지 확인한다.

관리자가 개인정보가 포함된 제보를 조회하는 기록은 일반 웹 서버 access log와 다르다. [개인정보의 안전성 확보조치 기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulId=73493&efYd=0)의 현행 접속기록 보존·점검·위변조 방지 요건을 실제 시스템에 적용한다. 짧은 오류·HTTP 로그 보존으로 법정 관리 기록을 대체하지 않는다.

지도·분석·crash·광고 SDK는 꼭 필요한 것만 추가한다. 스토어 개인정보 표시는 source code 의도만으로 작성하지 않고 release build의 네트워크와 실제 SDK 설정을 대조한다. 외부 AI에는 사용 허가가 있는 비개인 원문만 보낸다.

## 6 국외 처리와 자료 권리

개인정보 보호법 제28조의8에는 국외 이전의 여러 근거가 있다. 모든 이전에 무조건 동일한 동의가 필요하다고 단정하지 않고 실제 위탁·보관·제공 관계와 적용 근거를 확인한다. AWS 서울이라도 APNs·FCM·오류 SDK·분석·CI·LLM의 처리 국가와 재위탁은 별도로 조사한다. 초기 로컬 알림에는 서버 push token이 없으므로 그 부분의 데이터 흐름도 실제로 없는지 검증한다.

공개 웹에서 읽을 수 있는 조건과 앱에 저장·가공·배포할 권리는 구별한다. 저작권법 제93조는 데이터베이스의 상당 부분 또는 반복·체계적 이용 등을 다루므로 모든 개별 사실이 동일한 권리 상태라고 단정하지 않는다. 계약·이용조건·상표·이미지·데이터베이스 권리와 추출 규모를 함께 확인한다. 출처 표시만으로 배포 허가가 생기지 않는다.

특히 이 구조는 원시 규칙을 두 OS의 단말로 내려받는다. 앱 화면 표시만 허락받고 JSON 배포·오프라인 보존·업데이트·철회를 허락받지 않은 자료는 배포하지 않는다. 허가 요청 필드와 실제 예시는 [데이터 운영 문서](02_할인데이터_확보와_운영.md)를 따른다.

## 7 사고 대응과 일반 운영의 구분

침해를 인지하면 접속 차단·비밀 회전·증거 보전·영향 범위 확인·관련 연락을 즉시 시작한다. 서비스의 평일 지원창이나 주말 휴무로 법정 시계가 멈추지 않는다.

| 사건 | 확인한 공식 요건 | 운영에 반영할 것 |
|---|---|---|
| 정보통신망 침해사고 | KISA 안내에 인지 후 24시간 이내 신고 요건 제시 | 해당 사업 적용과 기산점 확인, 24시간 대응 연락망. 제보 inbox와 분리 |
| 개인정보 실제 유출 | 현행 시행령 제39조는 원칙적으로 인지 후 72시간 이내 정보주체 통지, 예외와 후속 통지 규정 | 피해자가 적어도 통지 문제를 검토. 전체 사실 확인까지 일괄 대기하지 않음 |
| 개인정보 유출 신고 | 제40조는 1천명 이상 또는 민감·고유식별정보 또는 외부 불법 접근 등의 조건과 72시간 기한 규정 | 이용자 수가 적다는 이유만으로 신고를 면제 판정하지 않음. 실제 예외는 확인 |
| 유출 가능성 | 2026-09-11 시행 개정의 제39조의3은 가능성 통지·추가 통지 절차도 다룸 | 유출 확정 여부만으로 대응을 닫지 않고 제39조의2 등의 대상·기산점 확인 |

근거는 [KISA 침해사고 신고 안내](https://www.krcert.or.kr/kr/subPage.do?menuNo=205033), [현행 개인정보 시행령 제39조](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900080824), [제39조의3과 제40조](https://www.law.go.kr/LSW/lumLsLinkPop.do?ancYnChk=0&chrClsCd=010202&lspttninfSeq=67073), [개인정보 유출 신고 시스템](https://brss.pipc.go.kr)이다. 사고 상황별 적용·예외·통지 내용을 확정하고 절차서에 넣는다. 24시간과 72시간은 서로 다른 의무를 비교하는 값이며 늦은 쪽 하나만 적용하는 기준이 아니다.

## 8 외부 확인에 전달할 질문

| 질문 | 준비 자료 | 해결 전 보류하는 범위 |
|---|---|---|
| 단말 위치 계산과 로컬 알림의 사업 분류·신고·소규모 자격은 무엇인가 | 아키텍처, OS API, 계정·좌표·서버 로그 흐름, 실제 사업자 정보 | 공용 위치 기능 제공 |
| 법정 위치 확인자료의 주체·필드·기간은 무엇인가 | 후보·발화·동의와 현재 삭제 정책 | 해당 기록 없이 위치 기능 활성화 |
| 사용자 선택 주변·지역 안내의 광고성 분류와 화면 요건은 무엇인가 | 실제 설정·동의·잠금화면·철회 화면과 문구 | 할인 자동 알림 |
| 공식 소스의 변환·B2C 단말 JSON·오프라인 보존을 어디까지 허용하는가 | URL·필드·두 OS 예시·갱신·캐시·철회·backup | 허가 불명 자료의 공개 배포 |
| SDK·AI·cloud의 국외 이전 근거와 고지 항목은 무엇인가 | SDK 목록, 실제 처리 국가·수탁사·데이터·기간 | 미확인 외부 전송 |
| 제보·접속 로그·연구·삭제·backup·사고 절차가 적절한가 | 항목별 목적·보존·packet·제보 삭제·복구 시험 | 검증되지 않은 공개 운영 약속 |

이 질문들은 프로젝트의 실제 설계를 검토하기 위한 것이며 특정 변호사·검수자·기관에 이미 전송하지 않았다.

## 9 출처 확인 상태

공식 페이지를 2026년 9월 30일 기준으로 조사했다. 상품 페이지는 연구 사례이며 사용 허가 목록이 아니다. 규정·가격·상품 조건은 실제 개발·계약·제출 시 재확인한다. 각 문서의 주장 가까이에 직접 링크를 두었다.

| 분야 | 주요 1차 자료와 위치 | 확인 범위 |
|---|---|---|
| iOS 위치·알림 | Apple Core Location·BackgroundTasks·UserNotifications, [위치 문서](01_위치알림_정책과_검증.md) | 공식 문서 본문. JS 문서는 공식 Markdown 본문도 이용 |
| Android 위치·알림 | Android Developers·Google Play policy, [위치 문서](01_위치알림_정책과_검증.md) | 지오펜스·배경 권한·지연·정책 본문 |
| RN·Expo·Docker·AWS 운영 | 각 제품 공식 문서, [아키텍처](03_아키텍처_Docker_AWS.md) | 빌드·네트워크·배포·백업·서비스 공지 |
| 카드·멤버십 | 신한 Mr.Life·SKT 파리바게뜨·KT 메가박스·U+ 등, [데이터 문서](02_할인데이터_확보와_운영.md) | 읽을 수 있는 공식 조건. 연구용 비교이며 원문 사용·JSON 배포 권리 미확보 |
| 점포 | 공공데이터포털 상가업소 API, [데이터 문서](02_할인데이터_확보와_운영.md) | 포털·이용조건·안내. 실제 호출과 계정 quota 미검증. 할인 수용 데이터 아님 |
| AWS 단가 | AWS Price List와 공식 요금표, [비용 문서](04_개발계획_비용_출시운영.md) | 리전·SKU·공개일·단가 확인과 예시 산식. 계정 bill·Calculator 확정 견적 아님 |
| 스토어 | Apple upcoming requirements·Play testing/device/API, [출시 문서](04_개발계획_비용_출시운영.md) | 공식 현재 요구. 계정 생성·테스트·제출·승인 없음 |
| 법률 | 국가법령정보센터의 개별 조문과 KISA 공식 안내 | 인용 조문 본문·시행일 확인. 실제 사업에 대한 유권해석 없음 |

Apple의 과거 Region Monitoring archive는 일부 역사적 제약의 참고이며 과거 기기의 지연값을 현재 SLA로 사용하지 않았다. KISA 제7차 안내는 게시물의 공식 개정 요약을 확인했고 첨부 PDF 전체는 읽지 못했다. 생활법령 개인정보 유출 해설은 2026-08-15 작성과 9월 개정 반영 예정 표시가 있어, 사고 요건에는 별도로 확인한 현행 시행령 본문을 사용했다.

안전성 확보조치 고시 링크의 현행 표제는 2026-07-01 시행으로 확인했으나 이 조사 도구에서 전체 본문을 읽지 못했다. 따라서 여기에는 특정 접속기록 기간을 확정 숫자로 제시하지 않았고, 실제 관리 기록의 요건을 공용 서비스 제공 전에 확인하는 항목으로 남겼다.

일부 JS·PDF 자료에서 확인하지 못한 상세 산식·조건·사용권은 미확인으로 남긴다. 예를 들어 멤버십의 천 원 단위 문구를 단순 10% 산식으로 바꾸거나 브랜드 존재를 카드 가맹점 수용으로 확정하지 않는다. 상품 조건의 연구 사례를 운영 데이터나 배포 허가의 증거로 사용하지 않는다.

## 10 결정 기록의 원칙

사용자 확정 조건, 공식 사실, 자체 가정, 미확인 사항을 같은 수준으로 쓰지 않는다. 법률·권리·기기·출시 의존조건이 해결됐다는 증거가 없으면 상태를 확인 필요로 유지한다. 반경·체류·오탐·배터리·공수·보존 제안은 실측·계약·외부 검토 후 버전과 변경 이유를 남긴다.
