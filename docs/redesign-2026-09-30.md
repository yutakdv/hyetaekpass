# 혜택패스 화면 리디자인

2026-09-30. 사용자는 현재 UI/UX를 다시 디자인하고 Pinterest 같은 디자인 사이트를 참고하라고 요청했다. 핵심 과업은 현재 매장에서 보유 카드·멤버십 중 확인된 유리한 방법을 찾고 코드를 제시하는 것이다. 기존 기능 범위 안에서 진행하며 계산·데이터 권리·단말 저장·UNKNOWN·삭제·인증 계약을 유지한다.

## 참고한 디자인

- [Pinterest / Rasel A. Clean Wallet](https://in.pinterest.com/pin/984036587323425864/): 밝은 배경과 카드 중심의 구성. 공개 핀을 확인했으며 로그인 이후 자료를 사용하지 않았다.
- [Dribbble / Mutahir Ali Mobile Wallet](https://dribbble.com/shots/26896708-Mobile-Wallet-App-UI-Design-Clean-Fintech-UX): 수단 카드의 시각 표현과 행동 위계. 실제 이미지를 브라우저에서 확인했다.

레이아웃 원리만 참고한다. 원본 이미지·타사 로고·가짜 잔고·가짜 거래·가짜 절감액은 앱에 넣지 않는다. 최종 디자인은 혜택패스 자체 컴포넌트와 기존 Ionicons/SVG로 만든다.
