# 혜택패스 Hyetaekpass

카드·멤버십 혜택을 결제 전에 확인하는 iOS·Android 앱을 만드는 프로젝트입니다. 로컬 지갑, 확인한 조건에 따른 예상 할인 계산, 주변 혜택 탐색을 제공할 계획입니다.

서비스명은 현재 가칭입니다. 한국 생활권 한 곳과 소량의 이용 가능한 데이터로 무료 검증판을 만드는 것부터 시작합니다.

## 현재 상태

2026년 9월 30일 기준 사업기획서 v3.1, 상세 기준 문서 6개, 개발 Goal과 Git 작업 지침을 관리합니다. 앱 소스, Docker 실행 구성, AWS 리소스, 스토어 바이너리는 아직 없습니다. 구현을 시작한 뒤 실제로 실행·검증한 내용에 맞춰 이 문서를 갱신합니다.

이용권, 실제 사람의 원문 검수, 실기기 시험, 사업·개인정보 절차, 스토어 승인은 별도 확인 사항입니다. 문서에 적힌 계획·예산·품질 기준은 이미 달성한 결과가 아닙니다.

## 제품 범위

- 지원되는 카드·멤버십을 단말에 등록하고 브랜드·점포·결제 채널을 직접 선택합니다.
- 필요한 조건에 “모름”을 선택할 수 있으며, 즉시 할인·현재 결제액·청구 할인을 구분합니다.
- 혜택의 출처·확인일·기간·사용 순서와 미확인 조건을 표시합니다.
- 위치·알림 권한을 거절해도 수동 기능을 유지하고, 전체 삭제 기능을 제공합니다.
- 전경 주변 탐색과 선택형 배경 알림은 권리·절차·플랫폼별 검증을 통과한 범위에서 제공합니다.

전국 혜택 자동 통합, 정확한 매장 입장 감지, 할인 적용 보장은 초기 제품의 약속이 아닙니다. 계정·지갑 동기화·금융 실적 자동 조회·결제·영수증 OCR·개인 쿠폰 자동 수집·B2B는 초기 범위에서 제외합니다.

## 개발 기본안

| 영역 | 계획 |
|---|---|
| 모바일 | React Native · TypeScript, iOS·Android 공통 앱 |
| 계산 | 단일 TypeScript 엔진, 단말에서 처리하고 관리 화면에서 재사용 |
| 백엔드 | Spring Boot · 지원되는 Java LTS · PostgreSQL, 단일 운영 서버 |
| 관리 화면 | 자료 검수·게시·차단·롤백·제보 처리 |
| 자료 보조 | 필요한 경우 Python CLI, 허가된 비개인 자료의 후보 작성·변경 비교 |
| 실행과 배포 | 로컬 Docker, 모바일 플랫폼 도구, AWS 운영 준비 |

사용자 지갑과 현재 위치는 기본적으로 단말에서 처리합니다. AI는 자료 후보를 돕는 도구이며 계산 승인이나 게시를 대신하지 않습니다. 자세한 계약과 구조는 아키텍처 문서가 기준입니다.

## 개발 Goal 실행

[GOAL_PROMPT.md](GOAL_PROMPT.md)에 확정 저장소 주소와 여섯 전문 에이전트의 역할, 구현 범위, 검증·완료 조건을 정리했습니다. [AGENTS.md](AGENTS.md)는 저장소 작업 지침입니다.

Codex에서 이 프로젝트를 열고 다음을 입력합니다.

```text
/goal 현재 프로젝트의 GOAL_PROMPT.md를 끝까지 읽고 그 목표·위임 범위·에이전트 역할·검증·완료 조건을 따라 혜택패스 검증판을 완성해라. 확정된 GitHub 저장소를 사용하고, 계획에서 끝내지 말고 구현과 실제 검증을 계속해라.
```

이 문서는 Goal 실행 지침이며 목표를 자동 활성화하지 않습니다. 개발 시작 시 실제 도구·기기·계정·이용권·검수자·예산을 확인하고, 외부 의존과 무관한 로컬 작업은 먼저 진행합니다.

## Git 작업

저장소는 [yutakdv/hyetaekpass](https://github.com/yutakdv/hyetaekpass)이며 비공개입니다. 기본 브랜치는 `main`, 현재 작업 폴더의 `origin`은 HTTPS 주소입니다.

```bash
git clone https://github.com/yutakdv/hyetaekpass.git
cd hyetaekpass
```

SSH 인증을 설정한 환경에서는 `git@github.com:yutakdv/hyetaekpass.git`으로 복제할 수 있습니다.

기능 작업은 `codex/<작업명>` 브랜치에서 진행합니다. 예를 들어 문서 개선 작업은 다음 순서로 시작합니다.

```bash
git switch main
git pull --ff-only
git switch -c codex/improve-docs
```

변경한 파일만 명시적으로 추가하고, 실제 확인 결과를 커밋·PR에 기록합니다. 커밋 메시지는 `docs:`, `feat:`, `fix:`, `chore:`처럼 목적을 짧게 표시합니다. 비밀·개인 자료·생성 결과는 제외하고, 라이브러리 잠금 파일은 버전 관리합니다. 원격 이력을 강제로 덮어쓰지 않습니다.

이 폴더의 독립 Git 저장소만 사용하며 상위 홈 디렉터리 저장소는 변경하지 않습니다. 아직 실행할 앱이나 서버가 없으므로 설치·실행 명령은 해당 구현의 검증 후 추가합니다.
