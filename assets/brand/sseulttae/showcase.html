쓸 때, 내 혜택을 한눈에.

지금 고른 매장에서 내 카드·멤버십을 확인하고, 유리한 조건을 고른 뒤 필요한 코드를 제시하는 도구.

선정

01 · 쓸 순간

두 카드의 둥근 면이 하나의 S로 이어집니다. 내 수단을 모아 결제 순간의 선택으로 잇는 흐름을 표현합니다. 작은 앱 아이콘에서도 남는 단일 실루엣을 최종 선정했습니다.

SVG 다운로드
Dot matrix

02 · 한 번의 픽

분리된 카드·멤버십 모듈이 아래의 넓은 선택 칸으로 모입니다. 도트 매트릭스 계열의 모듈성과 조건 비교를 강조했습니다.

SVG 다운로드
Line system

03 · 코드의 리듬

서로 다른 길이의 여섯 선이 바코드와 카드의 리듬을 만듭니다. 실제 스캔 코드가 아닌 제시 단계의 추상적 표식입니다.

SVG 다운로드
Dots + geometry

04 · 지금의 자리

둥근 장소 윤곽 속 한 점으로 지금 고른 매장을 표현합니다. 장소 맥락은 잘 전달하지만 지도 기능으로 오해할 여지가 있어 최종 심벌에서 제외했습니다.

SVG 다운로드
Lines + geometry

05 · 열린 지갑

지갑의 윤곽과 카드 입구를 선으로 연결합니다. 카드 관리 기능을 쉽게 읽을 수 있지만 작은 크기에서는 S 실루엣보다 세부 요소가 많습니다.

SVG 다운로드
Node network

06 · 맞는 조합

선택지들이 하나의 교차점에서 연결되는 구조입니다. 확인된 조건을 연결한다는 개념을 담았지만 서비스 아이콘으로는 도형의 밀도가 높습니다.
